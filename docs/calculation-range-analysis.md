# 計算ロジックの最大値・最小値分析

## 1. タイプ相性の倍率（effectiveness）の範囲

### 単一タイプの場合
- 最小値: 0（効果なし）
- 最大値: 2（効果ばつぐん）

### 二重タイプの場合
- 最小値: 0 × 0 = 0（効果なし）
- 最大値: 2 × 2 = 4（4倍）

**結論**: effectiveness の範囲は **0 ～ 4**

## 2. スコア変換（effectivenessToScore）の範囲

### 基本マッピング
- 0倍 → -4
- 0.25倍 → -3
- 0.5倍 → -2
- 1倍 → 0
- 2倍 → 2
- 4倍 → 4

### 線形補間による範囲
- 0 < effectiveness < 0.25: -4 ～ -3 の間（例: 0.125倍 → -3.5）
- 0.25 < effectiveness < 0.5: -3 ～ -2 の間（例: 0.375倍 → -2.5）
- 0.5 < effectiveness < 1: -2 ～ 0 の間（例: 0.75倍 → -1）
- 1 < effectiveness < 2: 0 ～ 2 の間（例: 1.5倍 → 1）
- 2 < effectiveness < 4: 2 ～ 4 の間（例: 3倍 → 3）

**結論**: スコアの範囲は **-4 ～ 4**

## 3. パーティ全体の合計値の範囲

### パーティの最大メンバー数
- 最大: 6匹

### 理論上の最小値
- 6匹全てが0倍（効果なし）の場合
- 計算: 6 × (-4) = **-24**

### 理論上の最大値
- 6匹全てが4倍の場合
- 計算: 6 × 4 = **24**

## 4. 実際の可能性

### 最小値に近いケース
- 例: 全てのメンバーが「ゴースト」タイプで、「ノーマル」タイプの攻撃を受ける場合
- 各メンバー: 0倍 → -4スコア
- 合計: -24

### 最大値に近いケース
- 例: 全てのメンバーが「ほのお/ひこう」タイプで、「いわ」タイプの攻撃を受ける場合
- 各メンバー: 0.5 × 2 = 1倍 → 0スコア（これは最大ではない）
- より極端な例: 全てのメンバーが「くさ/こおり」タイプで、「ほのお」タイプの攻撃を受ける場合
- 各メンバー: 2 × 2 = 4倍 → 4スコア
- 合計: 24

## まとめ

**理論上の範囲**:
- **最小値: -24**（6匹全てが0倍の場合）
- **最大値: 24**（6匹全てが4倍の場合）

**実際の使用範囲**:
- 通常のパーティ構成では、-20 ～ 20 程度の範囲になることが多い
- 全てのメンバーが同じ弱点を持つ極端なケースは稀
