# ポケモンパーティ弱点チェッカー

ポケモンのパーティを入力して、タイプ相性の弱点を視覚的に確認できるWebアプリケーションです。

## 機能

- パーティメンバーの追加・削除
- 各ポケモンの名前、タイプ1、タイプ2を入力
- パーティ全体の弱点を18種類のタイプについてビジュアライズ
- 弱点倍率に応じた色分け表示（×4倍は濃い赤、×2倍はオレンジ、×0倍は緑）
- リアルタイムで弱点表を更新

## 技術スタック

- **フレームワーク**: Next.js 14 (App Router)
- **言語**: TypeScript
- **スタイリング**: CSS Modules
- **デプロイ**: Vercel

## セットアップ

### 1. 依存関係のインストール

```bash
npm install
```

### 2. 開発サーバーの起動

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いて確認できます。

### 3. ビルド

```bash
npm run build
```

### 4. 本番環境で起動

```bash
npm start
```

1. Vercel CLIをインストール（初回のみ）
```bash

```

2. ログイン
```bash

```

3. デプロイ
```bash
vercel
```

初回は対話形式で設定を聞かれますが、デフォルトで問題ありません。

2. [Vercel](https://vercel.com)にアクセスしてログイン
3. 「New Project」をクリック
4. GitHubリポジトリを選択
5. フレームワークプリセットは「Next.js」を選択
6. 「Deploy」をクリック

以降、GitHubにプッシュするたびに自動でデプロイされます。

## 使用方法

1. ページを開くと、デフォルトでリザードン（ほのお、ひこう）が1匹登録されています
2. 「＋ メンバーを追加」ボタンでパーティメンバーを追加できます
3. 各ポケモンの名前、タイプ1、タイプ2を入力します
4. タイプ1で選択したタイプは、タイプ2の選択肢から除外されます
5. 弱点表がリアルタイムで更新され、色で弱点の危険度が表示されます
6. メンバーは「削除」ボタンで削除できます（最低1匹は残ります）

## 弱点の色分け

- **×4倍（濃い赤）**: 最も危険な弱点
- **×2倍（オレンジ）**: 危険な弱点
- **×1倍（薄い黄色）**: 通常ダメージ
- **×0.5倍（薄い青）**: 耐性がある
- **×0倍（薄い緑）**: 効果なし（無効）
